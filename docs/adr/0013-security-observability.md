# ADR 0013: Service security and observability

- **Status:** Accepted for Milestones 6–7
- **Context:** The public order API needs customer identity and ownership enforcement; operations writes and monitoring endpoints must be restricted. Operators need to follow an order across REST and at-least-once SNS/SQS delivery, observe queue and saga health, and use the same instrumentation locally and in AWS.
- **Decision:** All five services act as OAuth 2.0 JWT resource servers. They validate issuer, signature, timestamps, configured audience, and Cognito access-token type; roles map from supported Keycloak/Cognito claims to `CUSTOMER`, `OPERATIONS`, and `ADMIN`. Order reads use the token subject. Catalog reads are public; Catalog writes and Inventory reads/writes require OPERATIONS or ADMIN. Only health endpoints are public; other Actuator endpoints require ADMIN. ECS JSON logs include service/trace/span context and correlation ID. Micrometer exposes HTTP, consumer, queue/DLQ, order-outcome, and saga-duration measurements. W3C trace context is carried in message metadata. Prometheus scrapes locally; CloudWatch Agent scrapes service metrics in AWS. Micrometer Tracing exports OTLP to local Jaeger or an AWS ADOT Collector that exports to X-Ray.
- **Options:** Per-service custom authentication; shared gateway-only authorization; OIDC JWT validation at each service boundary. For telemetry: vendor-specific instrumentation; centralized agents with no service instrumentation; Micrometer/OpenTelemetry instrumentation with backend-specific collectors.
- **Trade-offs:** Every service needs issuer/JWKS/audience configuration and role mapping, increasing configuration responsibility but retaining boundary enforcement if services are reached internally. Prometheus scraping needs an ADMIN bearer token and private network reachability. Queue age/depth gauges poll SQS and can be temporarily stale or unavailable. Trace sampling is configurable; local defaults to full sampling while general service defaults are lower. Cognito and Keycloak claim formats differ, so only known role claims are mapped.
- **Operator configuration:** AWS deployments must provide Cognito user-pool issuer, JWKS URL, app-client ID, CloudWatch Agent scrape configuration/permissions, OTLP collector endpoint, and ADOT/X-Ray permissions. Local monitoring requires a short-lived ADMIN token in ignored `.local-data/prometheus/admin-token`.
